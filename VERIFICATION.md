# Проверка публикации

## Обновление PyTorch v2 — 12 ноября 2026

- Добавлены `train_torch.py` и `predict_torch.py`; их логика совпадает с локальными исходниками. Рабочие оригиналы, датасет и оба файла весов не изменены, хеши проверены.
- Проверен синтаксис всех скриптов. В изолированной папке на небольшом искусственном CSV выполнен полный цикл v2: обучение одной эпохи, валидация, сохранение, загрузка и предсказание. Это проверка работы кода, не метрика на RuReviews.
- Реальный локальный `sentiment_torch.pt` загружен с `weights_only=True`. Скрипт предсказания выполнен для обычного отзыва, пустого ввода и неизвестного слова. Проверено совпадение logits модели из скрипта оценки с исходным классом, а также неизменность результата при добавлении PAD.
- `compare_models.py` выполнен на реальном локальном корпусе и двух сохранённых моделях без повторного обучения: 3452 общих отложенных отзыва и отдельно полная validation v2 из 17 386 отзывов. Размеры словарей и восстановленные разбиения проверены; допущения о происхождении весов описаны в README и JSON.
- Подтверждено совпадение исходного корпуса и checkpoint v1 с хешами проверки 8 ноября. Для v1 совпали TF-IDF vocabulary/IDF, для v2 — весь `stoi` восстановленного train.
- Сравнительный график построен из опубликованного JSON и просмотрен. Веса, тексты отзывов и промежуточные рабочие файлы исключены из Git.

Полное обучение v2 на RuReviews заново не запускалось. Метрики получены оценкой уже сохранённой модели. Установка в чистое окружение не проверялась. Основное проверенное окружение: Python 3.13.2, PyTorch 2.14.1+cpu, pandas 3.0.6, scikit-learn 1.9.1, joblib 1.6.0; график построен с Matplotlib 3.10.3.
