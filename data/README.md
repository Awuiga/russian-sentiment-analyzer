# Данные

Источник: **RuReviews**, Sergey Smetanin и Michail Komarov, 2019.

- [Репозиторий и описание](https://github.com/sismetanin/rureviews).
- [Файл датасета](https://github.com/sismetanin/rureviews/blob/master/women-clothing-accessories.3-class.balanced.csv).
- [Лицензия источника Apache 2.0](https://github.com/sismetanin/rureviews/blob/master/LICENSE).
- Публикация: *Sentiment Analysis of Product Reviews in Russian using Convolutional Neural Networks*, DOI [10.1109/CBI.2019.00062](https://doi.org/10.1109/CBI.2019.00062).

Исходные тексты и их копии в этом репозитории не распространяются. Скачайте CSV отдельно и сохраните его рядом с этим README. Нужны столбцы `review` и `sentiment`, разделитель — табуляция. Модель проекта использует TF-IDF и логистическую регрессию; архитектура CNN из публикации об источнике здесь не реализована.
